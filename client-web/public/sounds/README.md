# Sounds

`kenney/` is Kenney's **Interface Sounds** pack (version 1.0), unchanged:
<https://kenney.nl/assets/interface-sounds>. Those files are **CC0**
(public domain, see `kenney/License.txt`), not AGPL; credit is optional
and given in Settings > Sounds anyway.

Sounds are picked per event in Settings > Sounds (`src/sounds.ts`).
Don't add files here unless their licence lets anyone redistribute the
raw files: everything in this folder is public in the repository and is
served by every OpenVoxa server.
